# Just Trim 1.1.1

By Shardul Narvekar. Private personal-development release.

- Drag one MOV from Explorer onto any part of the app, including the preview.
- Accept iPhone recordings containing the optional `cslg` timing summary; leave
  that summary out of exported clips while preserving actual frame timing.
- Correct signed QuickTime composition offsets and repeated sample-group slicing.
- Include the source, README, ownership guidance, proprietary app license, and
  third-party notices with the portable Windows application.

Extract the entire ZIP and launch `Just Trim.exe`. Keep `_internal` beside it.
Read `docs/VALIDATION.md` for test coverage and remaining compatibility limits.
Read `docs/DISTRIBUTION.md` before distributing the binary outside your account.
